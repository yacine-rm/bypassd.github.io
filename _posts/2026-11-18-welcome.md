This is the first post on the new site. It is here as a working example of the Markdown workflow, and you can replace it whenever you are ready.

## Writing a new article

Create a Markdown file in `_posts` using this filename format:

```text
_posts/2026-11-18-my-new-research.md
```

Each article starts with a small front matter block:

```yaml
---
title: "My new research"
date: 2026-11-18 10:00:00 +0100
description: "A short summary shown on the home page."
cover_image: "/assets/images/my-cover.png"
cover_alt: "Description of the cover image"
categories:
  - security
tags:
  - web
---
```

The rest of the file is normal Markdown. Headings automatically appear in the desktop table of contents, and code blocks receive syntax highlighting during the Jekyll build.

## Adding images

Upload an image to `assets/images`, then reference it with an absolute site path:

```markdown
![Useful alt text](/assets/images/example.png)
```

Keep the text concise, use descriptive alt text, and redact any data that should not be public.

## Editing the About page

The About page lives at `_tabs/about.md`. It uses the same Markdown format and is published at `/about/`.
